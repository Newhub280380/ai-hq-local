# ai-hq-local

Локальный AI-HQ: n8n-диспетчер, MetaGPT, UI-TARS и панель управления Android-устройствами.

> **Статус: репозиторий-заготовка.** На `main` пока нет исполняемого кода — только документация
> и CI-проверка структуры. Рабочий контур стека живёт на локальной машине и на сервере NAB9;
> этот репозиторий — точка входа, схема и документация, а не его замена.

Репозиторий создан 07.09.2026 (первый коммит — только README).

## Что входит в контур

| Слой | Назначение | Где работает сейчас |
|---|---|---|
| n8n-диспетчер | оркестрация сценариев, вебхуки, интеграции CRM / WhatsApp / Instagram | n8n на NAB9 (`100.115.202.74:5678`); конфиги и воркфлоу — `C:\BOX\01_CLOUD\beauty-art-stack` |
| LLM-шлюз | единая точка доступа к моделям (ключи не в git) | FreeLLM gateway `http://127.0.0.1:3001/v1`, ключ — env `FREELLMAPI_API_KEY` |
| Агентный слой | MetaGPT, agent-zero | agent-zero на NAB9 (`:5000`) |
| Веб-панель (HUB) | приборная панель и оболочка стека | NAB9 (`:7080`) |
| UI-TARS | управление GUI / браузером | в разработке, код пока не в этом репозитории |
| Android control panel | автоматизация Android-устройств (ADB) | в разработке, код пока не в этом репозитории |
| Skyvern | браузерная автоматизация | NAB9 (`:8000` / `:8080`) |

## Правила репозитория

- **Секреты не в git.** Только `.env.example` с плейсхолдерами; реальные значения — в
  `C:\BOX\00_INTERNET\secrets\*.env`. CI падает, если в репозитории появятся `.env`,
  `*.pem`, `*.key` или файлы в каталоге `secrets/`.
- **CI минимальный и честный:** проверяет структуру репозитория, а не «прогоняет» несуществующий код.
- **Медицинские заявления** — только med-only, пока не подтверждена РУ ZISHÉL.
- **Деплой** из этого репозитория не выполняется: он не содержит рантайма.
